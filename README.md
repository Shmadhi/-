
# 🫀 منصة نبض (Nabdh) — المساعد الذكي للزيارات الطبية

> **"لأن وقت الطبيب… للمريض"**

تطبيق ويب ذكي باللغة العربية يهدف إلى اختصار وقت أخذ التاريخ المرضي في العيادات، وتسهيل التواصل بين المريض والطبيب قبل بدء الموعد الطبي عبر تحويل البيانات إلى ملخص طبي موحد ورمز QR سريع القراءة.

---

## 📌 نبذة عن المشروع

يعاني المرضى والأطباء في العيادات من ضياع جزء كبير من وقت الاستشارة الثمين في جمع البيانات وتذكر الأعراض وتفتيش التقارير القديمة. 

يقدم **نبض** حلاً مبتكراً يتيح للمريض تعبئة أعراضه، أدوية، وتسجيل ملاحظاته الصوتية أو رفع تقاريره الطبية قبل الموعد. يقوم محرك الذكاء الاصطناعي بمعالجة البيانات وتحويلها فوراً إلى ملخص طبي قياسي وموحد مع رمز **QR Code** يقرأه الطبيب خلال 30 ثانية فقط.

### من خلال «نبض» يستطيع المريض:
* إدخال بياناته الأساسية وموعد الزيارة.
* كتابة الأعراض الرئيسية وتاريخ بدايتها وتطورها.
* إضافة الملاحظات والتفاصيل التي يريد تذكرها.
* تسجيل الأدوية الحالية والحالات الصحية السابقة.
* إرفاق صور التقارير والملفات الطبية (PDF).
* تسجيل ملاحظة صوتية اختيارية يتم تحليلها آلياً.
* إنشاء ملخص طبي منظم قابل للمشاركة.

### ويستطيع الطبيب:
* فتح الملخص عبر رابط مباشر أو مسح رمز **QR Code**.
* قراءة الأعراض والتاريخ الصحي والأدوية في لوحة تشخيصية شاملة ومختصرة.
* الاطلاع على المرفقات والملاحظات الصوتية المضافة.
* طباعة الملخص أو حفظه بصيغة PDF.

## 🛠️ التقنيات والأدوات المستخدمة

### الواجهة الأمامية (Frontend)
* **React / TypeScript / Vite / Tailwind CSS**
* **Wouter** لإدارة المسارات.
* **TanStack React Query** لإدارة طلبات البيانات والتخزين المؤقت.
* **Framer Motion** للتأثيرات الانتقالية.
* **Lucide React** للأيقونات ومكتبة **QRCode** لإنشاء رموز الاستجابة السريعة.

### الخادم وقواعد البيانات (Backend & DB)
* **Node.js / Express**
* **PostgreSQL** مع **Drizzle ORM**
* **Zod** للتحقق من البيانات.
* **OpenAPI** و **Orval** لتوليد واجهات TypeScript و React Query hooks.
* **معالجة الذكاء الاصطناعي (AI & LLM):** نماذج لغوية كبيرة لتلخيص النصوص وتحليل التسجيلات الصوتية واستخراج المصطلحات الطبية.

### المخططات وتجربة المستخدم
* **Mermaid / PlantUML** لتصميم مخططات العمليات (`As-Is` & `To-Be`).

## 🏗️ بنية المشروع (Project Structure)

```text
artifacts/
├── api-server/       # خادم API ومسارات الاستشارات
└── nabdh/            # تطبيق نبض وواجهته العربية

lib/
├── api-client-react/ # Hooks وواجهات العميل المولدة
├── api-spec/         # ملف OpenAPI الأساسي
├── api-zod/          # مخططات التحقق المولدة
└── db/               # مخطط قاعدة البيانات وDrizzle ORM

```

### أهم المسارات داخل التطبيق:

* `/` — بوابة المريض وإدخال البيانات لتوليد ملخص جديد.
* `/history` — سجل الملخصات والاستشارات المحفوظة.
* `/summary/:id` — لوحة تشخيص الطبيب الخاصة بالملخص، المشاركة، والطباعة.

## 🚀 خطوات تشغيل المشروع واستخدامه

### 1. الرابط المباشر

* يمكنك تجربة التطبيق مباشرة عبر الرابط التالي:
[https://nabdh-health-connect--lamar232004.replit.app](https://nabdh-health-connect--lamar232004.replit.app)

### 2. التشغيل المحلي (Local Setup)

**المتطلبات الأساسية:** `Node.js`, `pnpm`, `PostgreSQL`

```bash
# 1. تثبيت الاعتمادات
pnpm install

# 2. تشغيل خادم الـ API
pnpm --filter @workspace/api-server run dev

# 3. تشغيل واجهة التطبيق
pnpm --filter @workspace/nabdh run dev

# 4. فحص أنواع TypeScript
pnpm run typecheck

```

### 3. رحلة المريض (Patient Experience)

1. **أدخل:** تعبئة الأعراض الرئيسية، تاريخ ظهورها وتطورها، والأدوية الحالية.
2. **أرفق:** رفع الصور أو التقارير الطبية (PDF) أو تسجيل ملاحظات صوتية مباشرة.
3. **شارِك:** توليد ملخص طبي منظم وموحد يحتوي على رمز QR مخصص.

### 4. رحلة الطبيب (Doctor Experience)

* مسح رمز הـ QR الخاص بالمريض لعرض لوحة تشخيصية شاملة ومختصرة يمكن قراءتها فوراً أو حفظها كملف PDF / طباعتها.

## 📊 مؤشرات الأداء والأثر (KPIs)

* **وقت التاريخ المرضي:** انخفاض زمن مراجعة التاريخ المرضي من **8 دقائق** إلى **أقل من دقيقتين**.
* **توفير الوقت:** توفير **75%** من وقت أخذ التاريخ المرضي لصالح الفحص المباشر والتواصل الإنساني.
* **جودة المخرجات:** رفع دقة البيانات والحد من احتمالية نسيان التفاصيل الحرجة أثناء الاستشارة.
