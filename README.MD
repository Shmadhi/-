# نبض (Nabdh)

## فكرة المشروع

«نبض» هو تطبيق ويب عربي يساعد المرضى ومقدمي الرعاية على تجهيز معلوماتهم الصحية قبل موعد الطبيب، ثم يحوّلها إلى ملخص طبي واضح وسريع القراءة.

يهدف المشروع إلى تقليل الوقت الذي يقضيه الطبيب في جمع المعلومات الأساسية والمتكررة، ومساعدة المريض على تذكر الأعراض والتفاصيل المهمة أثناء الزيارة، خصوصًا عندما يكون متوترًا أو لا يعرف المصطلحات الطبية المناسبة.

من خلال «نبض» يستطيع المريض:

- إدخال بياناته الأساسية وموعد الزيارة.
- كتابة الأعراض الرئيسية وتاريخ بدايتها.
- إضافة الملاحظات والتفاصيل التي يريد تذكرها.
- تسجيل الأدوية الحالية والحالات الصحية السابقة.
- إرفاق صور التقارير والملفات الطبية.
- تسجيل ملاحظة صوتية اختيارية.
- إنشاء ملخص طبي منظم قابل للمشاركة.

ويستطيع الطبيب:

- فتح الملخص من خلال رابط مباشر أو رمز QR.
- قراءة الأعراض والتاريخ الصحي والأدوية خلال وقت قصير.
- الاطلاع على المرفقات المضافة من المريض.
- طباعة الملخص أو حفظه بصيغة PDF.

## طريقة استخدام المشروع

### للمريض

1. افتح الصفحة الرئيسية للتطبيق.
2. أدخل الاسم والعمر وموعد الزيارة.
3. اكتب العرض الأساسي وتاريخ بداية الأعراض.
4. أضف الملاحظات والأدوية والحالات الصحية السابقة.
5. أرفق التقارير أو الصور الطبية، وسجل ملاحظة صوتية عند الحاجة.
6. راجع البيانات في الخطوة الأخيرة.
7. اضغط على **احفظ ملخصي**.
8. استخدم رابط المشاركة أو رمز QR لإرسال الملخص إلى الطبيب.

### للطبيب

1. افتح رابط الملخص الذي شاركه المريض، أو امسح رمز QR.
2. راجع العرض الأساسي وتاريخ بداية الأعراض.
3. اطلع على الأدوية والحالات الصحية والملاحظات والمرفقات.
4. استخدم زر **طباعة / حفظ PDF** للاحتفاظ بنسخة من الملخص عند الحاجة.

### سجل الاستشارات

من خلال صفحة **سجلاتي** يمكن استعراض الملخصات التي تم حفظها وفتح أي ملخص سابق مرة أخرى.

## تشغيل المشروع محليًا

### المتطلبات

- Node.js
- pnpm
- PostgreSQL

### تثبيت الاعتمادات

```bash
pnpm install
```

### تشغيل خادم API

```bash
pnpm --filter @workspace/api-server run dev
```

### تشغيل واجهة التطبيق

```bash
pnpm --filter @workspace/nabdh run dev
```

### فحص أنواع TypeScript

```bash
pnpm run typecheck
```

## بنية المشروع

```text
artifacts/
├── api-server/       # خادم API ومسارات الاستشارات
└── nabdh/            # تطبيق نبض وواجهته العربية

lib/
├── api-client-react/ # Hooks وواجهات العميل المولدة
├── api-spec/         # ملف OpenAPI الأساسي
├── api-zod/          # مخططات التحقق المولدة
└── db/               # مخطط قاعدة البيانات وDrizzle ORM
```

## أهم المسارات داخل التطبيق

- `/` — بوابة المريض وإنشاء ملخص جديد.
- `/history` — عرض الملخصات المحفوظة.
- `/summary/:id` — صفحة ملخص الطبيب والمشاركة والطباعة.

## ملاحظات مهمة

- الواجهة مصممة باللغة العربية وتدعم الاتجاه من اليمين إلى اليسار (RTL).
- التطبيق يحفظ بيانات الاستشارات في قاعدة بيانات PostgreSQL.
- بيانات المرفقات الحالية تشمل اسم الملف ونوعه وحجمه داخل الملخص.
- رابط المشاركة مخصص لكل استشارة ويتم إنشاء رمز QR له.
- التطبيق لا يقدم تشخيصًا طبيًا، بل يساعد على تنظيم المعلومات قبل زيارة الطبيب.

## الهدف من المشروع

تقليل وقت جمع التاريخ المرضي من عدة دقائق إلى أقل من دقيقتين، حتى يتمكن الطبيب من التركيز بشكل أكبر على الفحص والتشخيص والعلاج.
